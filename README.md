# 保持亮屏（KeepAwake）

一个**只有控制中心磁贴**的应用：

- **没有可打开的界面，没有桌面图标**（清单里没有任何启动入口，装完桌面上找不到它）。
- 在**控制中心（快速设置面板）**里提供一枚「保持亮屏」磁贴，可自由添加。
- **点一下磁贴 = 开启**：屏幕保持亮起，磁贴高亮，副标题显示**剩余时间**（Android 10+）；
  同时常驻一条**显示剩余亮屏时间的通知**（秒级倒计时，带「关闭」按钮）。
- **再点一下 = 关闭**（或点通知上的「关闭」）：恢复正常熄屏。
- **长按磁贴弹出菜单**选择保持亮屏的时长：**5 分钟（默认）／30 分钟／常亮**。
- **不修改任何系统设置**（屏幕超时时间原样不动），卸载后无需清理任何东西。

支持 Android 8.0+（minSdk 26）；不依赖任何第三方库，APK 32 KB。

## 使用

1. 构建并安装（见文末「构建」）：`adb install -r dist/keepawake-1.1.apk`
2. 下拉控制中心 → 点「编辑」（铅笔图标）→ 把「**保持亮屏**」拖进磁贴区。
3. **首次点磁贴会跳到系统的「显示在其他应用上层」授权页**——这是本方案唯一需要
   手动开的一次性权限；打开开关、返回，**再点一次磁贴**即开启。
4. 之后：
   - **点按**：开启 / 关闭保持亮屏
   - **长按**：弹出时长菜单（5 分钟 / 30 分钟 / 常亮，默认勾选 5 分钟）
5. Android 13+：如果系统没有自动弹「显示通知」授权，第一次**长按**磁贴时会请求一次
   （只为显示剩余时间的倒计时通知；不给也能正常亮屏，只是通知可能不显示）。

### 时长语义

| 档位 | 行为 |
|---|---|
| 5 分钟 / 30 分钟 | 从**开启那一刻**起算；到点悬浮窗被撤掉，恢复系统正常超时（最后一次触摸之后按系统设置的时间熄屏）。磁贴状态在下次打开面板时同步为「关闭」 |
| 常亮 | 一直亮着，直到你再点一下磁贴（或通知上的「关闭」） |

- 开启期间按**电源键**依然可以强制熄屏；再次点亮屏幕后继续保持亮屏（会话没结束）。
- 开着的状态在**重启手机**后会自动恢复（定时档按剩余时间续算；已过点则自动收尾）。
- 覆盖安装升级不会丢状态。

## 工作原理

- **保持亮屏本体**：前台服务（`specialUse` 类型）挂一个 **1×1 全透明悬浮窗**，
  窗口带 `FLAG_KEEP_SCREEN_ON` —— 官方推荐的保持亮屏方式，窗口可见期间系统
  不会让屏幕超时熄灭。
- **常驻通知**：同一条前台通知秒级刷新，正文显示「剩余 04:32」或「常亮中」，
  右侧「关闭」按钮 = 一键收摊。通知渠道为 `IMPORTANCE_LOW`：不响铃、不弹横幅。
- **状态**：SharedPreferences 只记三件事 —— 是否开启、时长档位、结束时刻（墙钟毫秒）。
- **自愈**（保证「状态说开着 = 真的有窗口挂着」）：
  1. 服务本身是 `START_STICKY`：被系统杀掉会自动重启，按 prefs 恢复现场；
  2. **打开控制中心**时磁贴 `onStartListening` 先 `recover()` 对齐状态再刷新显示；
  3. **心跳闹钟**（10 分钟，`setAndAllowWhileIdle`，Doze 下也会醒）把服务补回来；
  4. **到点闹钟**兜底：服务万一没跑起来，到点把状态收掉（只在真的过期时才清，
     没到点绝不会被误清理）；
  5. **开机 / 覆盖安装**广播后恢复，并重排闹钟。
- 磁贴被**移除**时自动收尾（不然就没有任何关闭入口了）。
- 改档位时只重算结束时刻，服务的秒级 tick 直接读状态，1 秒内生效，无需重启服务。

## 权限

| 权限 | 类型 | 用途 |
|---|---|---|
| `SYSTEM_ALERT_WINDOW` | 特殊权限，**需一次性手动开启** | 挂 1×1 悬浮窗（首次点磁贴自动跳授权页） |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_SPECIAL_USE` | 普通，安装即授予 | 前台服务（保活 + 常驻通知） |
| `POST_NOTIFICATIONS` | 运行时权限，仅 Android 13+ | 显示倒计时通知（长按菜单时请求） |
| `RECEIVE_BOOT_COMPLETED` | 普通，安装即授予 | 重启后恢复会话 |

没有 `WRITE_SETTINGS`、没有改任何系统设置、没有悬浮窗之外的敏感权限。

## 已知限制（选型说明）

1. 1×1 悬浮窗 + `FLAG_KEEP_SCREEN_ON` 是社区成熟做法、官方认可的保持亮屏机制；
   但仍受个别 ROM 的悬浮窗/后台管控影响（如部分国产 ROM 的「悬浮窗权限」
   「后台弹出界面」开关）。装好后可以这样验证：

   ```bash
   adb shell dumpsys window | grep -i keepawake   # 有输出 = 窗口挂着且带 KEEP_SCREEN_ON
   adb shell dumpsys power | grep -i screen       # 看屏幕超时是否被推后
   adb logcat -s KeepAwake                        # 开/关/自愈/到点的内部日志
   ```

   如果你的设备上无效，备选方案是「修改系统设置（WRITE_SETTINGS）改屏幕超时」
   （需要不同的一次性授权，且**卸载后会残留被改过的超时值**，故未选它）。
2. 服务若被系统强杀且粘性重启失败，窗口随进程消失 —— 屏幕**提前**按系统超时熄屏
   （方向是安全的：宁可提前熄，不会多亮）。打开控制中心或下一次心跳会自动补回。
3. Android 14+ 上划掉常驻通知会停止前台服务（这是系统行为）；会话状态还在，
   下次打开面板 / 心跳会把窗口和通知重新拉回来。**真正的关闭请用磁贴或通知的
   「关闭」按钮**。
4. 对应用「强行停止」后闹钟会停（Android 对 force-stop 的统一行为）；
   再次打开控制中心或重启手机即可恢复。强行停止时窗口已被系统撤掉，无残留行为。
5. 定时档到点后，屏幕是按系统正常超时熄（若你最后一秒刚碰过屏幕，会再多亮几秒）；
   磁贴显示的纠正发生在下次打开控制中心时。

## 构建

```bash
./build.sh            # 产出 dist/keepawake-1.1.apk（32 KB）
./build.sh --clean    # 清掉构建目录重来
DEBUGGABLE=1 ./build.sh   # 打 android:debuggable 的调试版
```

构建环境**完全复用 CountDay 的隔离环境**（`~/.countday-env`：JDK 17 + build-tools 34 +
platform-34 + 调试签名证书），**只读使用，不做任何修改**，也不写 `~/.gradle`、`~/.android`
或系统目录。可用 `KEEPAWAKE_ENV` / `COUNTDAY_ENV` 指定其它环境目录。

## 测试

```bash
./test/sim.sh     # 主机端自检，不需要设备
```

包含两部分（当前共 35 项断言，全部通过）：

1. **Policy 纯逻辑单元测试** —— 时长档位、菜单项映射、到期判定、副标题取整、
   通知倒计时文案，用环境里的 JDK 直接 `javac` + `java` 跑断言；
2. **清单静态检查** —— 磁贴入口、长按菜单入口、无桌面图标、
   悬浮窗/前台服务/通知权限声明、不含已废弃的 `WAKE_LOCK` / `WRITE_SETTINGS`。

设备端手工验收建议：

1. 添加磁贴 → 首次点按 → 应跳到「显示在其他应用上层」→ 打开开关、返回；
2. 再点磁贴 → 磁贴高亮 + 出现「剩余 05:00」副标题 + **倒计时常驻通知**；
3. 放着不动 1 分钟（系统超时短于 1 分钟），屏幕**不熄**；
4. `adb shell dumpsys window | grep -i keepawake` 确认悬浮窗挂着；
5. 长按 → 弹出三选一菜单 → 改「常亮」→ 通知变「常亮中」、副标题变「常亮」；
6. 点通知上的「关闭」→ 屏幕恢复系统超时、通知消失、磁贴变灰；
7. 改回「5 分钟」并开启 → 到点自动恢复正常熄屏逻辑；
8. 开启状态下重启手机 → 状态按剩余时间恢复；
9. 卸载 → 什么残留都没有（本来就没改过系统设置）。

## 项目结构

```
keepawake/
├── build.sh                  # 构建脚本（复用 countday 环境，只读）
├── test/
│   ├── sim.sh                # 主机端自检（单元测试 + 清单检查）
│   └── TestMain.java         # Policy 单元测试
└── app/src/main/
    ├── AndroidManifest.xml   # 无启动入口；磁贴/前台服务/长按菜单/广播接收器
    ├── java/io/giasinton/keepawake/
    │   ├── Policy.java               # 纯逻辑（无 Android 依赖，可主机测试）
    │   ├── Keeper.java               # 会话状态 + 服务启停 + 闹钟自愈 + 授权引导
    │   ├── KeepAwakeService.java      # 前台服务：1×1 悬浮窗 + 倒计时常驻通知
    │   ├── KeepAwakeTileService.java  # 控制中心磁贴（点按开关）
    │   ├── DurationPickerActivity.java # 长按时长菜单（仅 QS 可启动）
    │   ├── InternalReceiver.java      # 应用内部广播：心跳/到点/通知关闭按钮
    │   └── WakeReceiver.java          # 系统广播：开机/升级恢复
    └── res/
        ├── values/strings.xml        # 「保持亮屏」等文案
        ├── values/styles.xml         # 菜单页透明主题
        └── drawable/                  # 磁贴图标 / 应用图标（矢量）
```
